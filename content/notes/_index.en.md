Each note covers one problem that took a while to understand and describes
what the repository does about it now. These explanations have their own
pages because the answer to each problem is spread over several files, such
as a configuration file, a script and a CI job, and none of those files is a
good place to explain the whole thing.

All timings and counts in the notes were measured on one machine, which is
described in [The machine](/machine/). That page lets you judge which of
the numbers would apply to your own setup.
