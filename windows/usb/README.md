# windows/usb

USB の省電力設定をまとめてトグルするスクリプト。

## これは 2026 年 6 月のマウス切断の原因ではなかった

2.4GHz 無線マウス (`VID_056E&PID_0183`) の切断は、**電池の消耗**と、レシーバと
マウスの間に**木の板が入っていたこと**の二重要因だった。どちらも解消して解決
している。

当時この設定を疑ったのは、着脱イベント (Kernel-PnP 410/411) が一切記録されて
いないこと（＝コネクタ側の問題ではない）と、`2026-06-22 12:37` の KB5094126 で
USB/HID ドライバスタックが同時刻に差し替わっていたことが根拠だった。前者は
正しく、後者は相関にすぎなかった。

7 月の累積更新でこの設定は Windows 既定に戻っており、その状態でマウスは正常に
動いている。設定は原因ではない。

同時期の USB オーディオの不調をマウスと同じ原因に束ねたことが、共通ドライバ
スタックという仮説を魅力的にした。両者が関係あるかは確かめていない。

## スクリプト

手の下でデバイスがサスペンドされる、という**本当にその症状が出た場合**に使う。

| ファイル | 内容 |
| --- | --- |
| `fix-usb.ps1` | USB セレクティブサスペンド (AC/DC) を無効化し、全 USB デバイスの「電力節約でオフ」フラグをクリアする |
| `restore-usb.ps1` | 上記を Windows 既定（有効）に戻す |

## 使い方

どちらも管理者権限が必要。`sudo` (Sudo for Windows) 経由で実行する。

```pwsh
# 適用（省電力を無効化する）
sudo pwsh -NoProfile -ExecutionPolicy Bypass -File V:\dotfiles\windows\usb\fix-usb.ps1

# 元に戻す（Windows 既定へ）
sudo pwsh -NoProfile -ExecutionPolicy Bypass -File V:\dotfiles\windows\usb\restore-usb.ps1
```

## 補足

- `fix-usb.ps1` は `Enable=$true` のデバイスのみ、`restore-usb.ps1` は
  `Enable=$false` のデバイスのみを対象にするため、繰り返し実行しても安全。
- USB ドライバスタックを差し替える累積更新が入ると、`fix-usb.ps1` の変更は
  Windows 既定に戻る。適用したまま維持したいなら更新のたびに確認が要る。
- 設定は即時反映されるが、確実を期すならデバイスの挿し直しか再起動を行う。
